The World Today — a program that draws one newspaper front page summing up the world's news of Wednesday 25 November 2026: two oil tankers hit naval mines in the Strait of Hormuz, Shenzhou-24 docks at Tiangong with Pakistan's first astronaut, a fuel tanker fire kills 31 in Cairo, the Solomon Islands–Australia security treaty, Bangladesh's 36% garment wage rise, and the Houthi strike on Saudi Arabia's Ras Tanura refinery. Everything is drawn in code: a small software rasterizer, a 5x7 bitmap font, and a PNG encoder built on node:zlib. No network, no files read, no randomness — two runs write the same bytes.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
